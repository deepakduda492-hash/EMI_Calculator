# 💰 EMI Calculator

A clean and responsive **EMI (Equated Monthly Installment) Calculator** built with HTML, CSS, and JavaScript. Enter your loan details and instantly calculate your monthly EMI.

---

## 🖥️ Live Preview

> Open `emi_calculator.html` in any browser to run the app locally.

---

## ✨ Features

- 📥 Input fields for **Loan Amount**, **Interest Rate**, and **Tenure (Months)**
- ⚡ Instant EMI calculation on button click
- ✅ Input validation — alerts if any field is left empty
- 🎨 Clean, modern UI with smooth hover effects
- 📱 Responsive design centered layout

---

## 🧮 EMI Formula Used

```
EMI = P × r × (1 + r)^n / ((1 + r)^n - 1)
```

Where:
- **P** = Principal Loan Amount
- **r** = Monthly Interest Rate (Annual Rate ÷ 1200)
- **n** = Number of Monthly Installments (Tenure)
